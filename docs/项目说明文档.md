# AI 音乐生成系统 —— 项目说明文档

> 环境音 + 语音/文字 → 云端多模型流水线智能作曲 · ESP32 端到端硬件播放终端

---

## 一、产品简介

**AI 音乐生成系统**是一套"从生活场景到音乐成片"的端到端解决方案。用户只需**对着设备说一句话、放一段环境音**（雨声、车流、海浪……），或直接输入一段文字，系统便会自动完成从"环境理解 → 语音识别 → 歌词创作 → 音乐生成 → 成片播放"的完整创作闭环，最终通过 ESP32 硬件终端或网页直接播放整首成品音乐。

系统采用**云端多模型流水线**架构，将"理解"与"创作"解耦为多个可插拔的 AI 能力模块，硬件端使用 ESP32-S3 实现录音上传、整首下载与解码播放，形成一套软硬件一体、真实可演示的 AI 应用。

## 二、功能特性

### 1. 多模态输入创作
- **环境音理解**：上传雨声、街道、海浪等环境录音，AI 自动识别场景、情绪与节奏
- **语音创作**：直接录制语音，AI 识别你的想法并谱曲
- **文字创作**：输入任意文字，AI 即兴作词作曲
- 三种输入方式可自由组合，灵活度高

### 2. 智能完整创作链路
- 自动生成**歌词**（含主歌/副歌结构）
- 自动生成**音乐风格描述**（曲风、BPM、乐器、情绪）
- 自动生成**英文歌名**
- 输出完整可播放的 MP3 成片（目标时长 60–90 秒）

### 3. 多音乐引擎热切换
- **阿里云百炼 Fun-Music**（默认可演唱歌词）
- **MiniMax Music**（可切换）
- 支持**纯音乐 / 带人声**两种模式
- 支持 **Mock 模式**，无 API Key 也能跑通全链路演示

### 4. 硬件终端（ESP32-S3）
- **录音上传**：板载麦克风（INMP441）录制环境音/语音上传云端
- **整首播放**：下载成片到 PSRAM → MP3 解码 → I2S 功放 (MAX98357A) 驱动喇叭
- **触摸屏**：2.8 寸触摸彩屏，支持配网、选择、播放控制
- **WiFiManager 配网**：手机热点即可快速接入

### 5. Web 控制台
- 生成日志实时监控（仅展示生成过程，可一键清空）
- 历史成片列表（在线播放 / 删除）
- 录音上传管理
- 音乐后端热切换（无需改配置、无需重启）

### 6. 安全保障
- API Key 仅存本地 `.env`，不提交仓库
- 简易鉴权（密码登录 + 设备 `X-API-Key` 头），防公网盗刷

## 三、产品亮点

### 1. 真正"从声音到音乐"的闭环
不是简单的"文字生成音乐"，而是能**听懂环境音**——把雨声、车流、海浪等生活场景转化为音乐灵感，让创作充满真实感与故事性，构建完整的多模态输入体验。

### 2. 软硬件一体，真实可演示
既有功能完整的 Web 控制台，又有**真实可运行的 ESP32 硬件终端**（录音、云端生成、整首下载、功放播放），软硬件链路全部打通，适合现场演示与评委体验。

### 3. 模块化可插拔架构
云端能力按"理解 / ASR / 歌词 / 音乐"解耦为标准接口，音乐后端可一键热切换（Fun-Music / MiniMax / Mock），扩展性强，便于接入更多模型。

### 4. 低成本、零 GPU 依赖
音乐生成全部走云端 API，**不占用本地 GPU 资源**，单机即可运行，硬件仅需一块 ESP32 开发板，成本可控、易复现。

### 5. 完善的工程化设计
- 结构化 JSON 输出、错误兜底、Mock 降级
- 生成日志分级过滤、耗时统计
- 严谨的鉴权与密钥管理
- 详尽的固件交接与技术文档

## 四、技术方案特色

### 1. 系统架构

```
浏览器 / ESP32 硬件终端
        │  HTTP
        ▼
Flask 后端（app.py）──编排──►  CloudPipeline 流水线
        │                          │
        │              ┌───────────┴────────────┐
        │              ▼                        ▼
        │   阿里云百炼 DashScope 三步     音乐生成后端（可插拔）
        │     ① 环境音理解 qwen3-omni-flash   Fun-Music / MiniMax
        │     ② ASR         qwen3-asr-flash   （含 Mock 降级）
        │     ③ 歌词+风格   qwen-plus
        │
        ├── static/uploads/  浏览器/板端录音
        └── static/outputs/  音乐成片（MP3）
```

### 2. 四步智能流水线

| 步骤 | 能力 | 模型 | 输入 → 输出 |
|------|------|------|-------------|
| ① 环境音理解 | 全模态理解 | `qwen3-omni-flash` | 环境音 → 场景/情绪/节奏描述 |
| ② 语音识别 | ASR | `qwen3-asr-flash` | 语音 → 文字（有文字则跳过） |
| ③ 歌词创作 | 文本生成 | `qwen-plus` | 场景+文字 → 歌词+风格+歌名(JSON) |
| ④ 音乐生成 | 音乐生成 | Fun-Music / MiniMax | 风格+歌词 → 完整 MP3 成片 |

### 3. 关键技术设计

- **全模态理解模型**：采用 `qwen3-omni-flash` 新一代全模态模型（支持音频+文本混合输入、百万级 token），替代受限的音频专用模型，作为可持续的长期方案。
- **可插拔音乐后端**：统一 `text_to_music(prompt, duration_sec, lyrics)` 接口，Fun-Music 与 MiniMax 语义差异在适配层抹平，实现无缝切换。
- **时长软控制**：音乐生成 API 无硬时长参数，采用"短歌词 + prompt 软提示"将成片控制在约 90 秒内，便于 ESP32 整首缓存播放，不截断音频。
- **Mock 降级机制**：未配置 API Key 时自动降级为本地 Mock，保证全链路可演示、可测试。
- **文件即产物**：本地音频自动上传 OSS 交给模型，成片直接落盘为 MP3 文件，命名规范（`模型-日期时间.mp3`）。

### 4. 硬件方案（ESP32-S3）

- **主控**：ESP32-S3-N16R8（板载 16MB Flash + 8MB PSRAM）
- **显示交互**：2.8 寸彩色触摸屏（LVGL 界面）
- **音频采集**：INMP441 I2S 数字麦克风
- **音频播放**：MAX98357A I2S 功放 + 喇叭
- **播放链路**：整首下载到 PSRAM → MP3 解码 → I2S 输出（支持流式，默认关闭）
- **配网**：WiFiManager 门户（AP：`AI-Music-Setup`），可配置后端 Host/Port/HTTPS

### 5. 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Python 3.13 · Flask · Gunicorn |
| 云端 AI | 阿里云百炼 DashScope（Omni / ASR / Qwen）· Fun-Music · MiniMax |
| 网页 | HTML · 原生 JS（单页控制台） |
| 硬件 | ESP32-S3 · ESP-IDF 5.5 · PlatformIO · LVGL · WiFiManager |
| 接口 | REST API（multipart 上传 / JSON / 文件下载） |
