# ESP32 外设接线指南

> 板子: VIEWE UEDX24320028E-WB-A (ESP32-S3-N16R8)  
> 引脚定义来源: `esp32_firmware_idf55/src/config.h`（以此为准）  
> 更新: 2026-07-23

---

## 0. 先断电，再接线

1. 拔掉 USB / 断电  
2. 按下面两表接完  
3. 再通电  
4. 串口应看到功放初始化成功日志

---

## 1. MAX98357A 功放 (I2S1, TX)

### 开发板 → 功放

| 开发板 | MAX98357A | 作用 |
|--------|-----------|------|
| **5V** | VIN / VDD | 供电 |
| **GND** | GND | 共地 |
| **IO14** | BCLK | 位时钟 |
| **IO5** | LRC / LRCLK | 左右时钟 |
| **IO6** | DIN | 音频数据 (ESP → 功放) |
| **3V3** | SD / SD_MODE | 使能 + 左声道 |

| MAX98357A | 接法 |
|-----------|------|
| GAIN | **悬空**（默认约 9dB） |

### 功放 → 喇叭

| MAX98357A | 喇叭 |
|-----------|------|
| OUT+ | 喇叭 +（红） |
| OUT- | 喇叭 −（黑） |

```
  开发板                     MAX98357A                  喇叭
  ┌──────┐                  ┌──────────┐              ┌──────┐
  │  5V  │─────────────────>│ VIN      │              │      │
  │ GND  │─────────────────>│ GND      │              │  +   │<── OUT+
  │ IO14 │─────────────────>│ BCLK     │── OUT+ ────>│      │
  │ IO5  │─────────────────>│ LRC      │── OUT- ────>│  -   │
  │ IO6  │─────────────────>│ DIN      │              └──────┘
  │ 3V3  │─────────────────>│ SD       │
  └──────┘                  │ GAIN(空) │
                            └──────────┘
```

## 2. INMP441 麦克风 (I2S0, RX)

> 与功放**独立总线**，时钟线不要并接。

### 开发板 → 麦克风

| 开发板 | INMP441 | 作用 |
|--------|---------|------|
| **3V3** | VDD | 供电 |
| **GND** | GND | 共地 |
| **IO10** | SCK / BCLK | 位时钟 |
| **IO11** | WS / LRCLK | 左右时钟 |
| **IO12** | SD / DOUT | 数据 (麦 → ESP) |

| INMP441 | 接法 |
|---------|------|
| L/R | **GND**（左声道，单声道录音） |

```
  开发板                     INMP441
  ┌──────┐                  ┌──────────┐
  │ 3V3  │─────────────────>│ VDD      │
  │ GND  │─────────────────>│ GND      │
  │ IO10 │─────────────────>│ SCK      │
  │ IO11 │─────────────────>│ WS       │
  │ IO12 │<─────────────────│ SD/DOUT  │
  │ GND  │─────────────────>│ L/R      │
  └──────┘                  └──────────┘
```

---

## 3. 一览（对照固件）

| 外设 | BCLK | WS/LRC | DATA | 总线 |
|------|------|--------|------|------|
| 麦克风 INMP441 | IO10 | IO11 | IO12 | I2S0 |
| 功放 MAX98357A | IO14 | IO5 | IO6 | I2S1 |

**不要接这些孔给音频：**

| GPIO | 原因 |
|------|------|
| 13 | 背光 |
| 15–18 | SD 卡 |
| 1, 3 | 触摸 |
| 19, 20 | USB |
| 43, 44 | UART |

---

## 4. 注意事项

1. **先接线后通电**，不要带电插拔  
2. **功放 VIN=5V，麦克风 VDD=3V3**，不要反  
3. **功放 SD 接 3V3**（使能），**GAIN 悬空**  
4. **麦 L/R 接 GND**  
5. 两路 I2S **不共用** BCLK/WS  
6. 当前 UI 是触摸屏；**GPIO14 只给功放 BCLK**，不要再当 User 键用  
7. 验证：串口出现 `[play] MAX98357A I2S1 init OK` 表示功放初始化成功
